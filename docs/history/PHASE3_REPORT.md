# Phase 3 — Coordinator Tendency Table

## What's built

- `src/coordinator/oc_assignments.csv` — manually curated OC → team → season
  mapping, 320 rows (32 teams × 2016-2025). Columns: `season, team, oc_name,
  first_year_in_seat, promotion_type (internal|outside_hire|returning),
  prior_team, prior_role, hc_is_playcaller, confidence (high|medium|low),
  notes`. This is the source-of-truth data file — human-editable, not
  regenerated by code. `hc_is_playcaller` is an addition beyond the spec's
  minimum columns: several franchises (Shanahan/SF, McVay-tree/LA, LaFleur/GB,
  Payton/NO, Reid/KC, McDaniel/MIA) are well documented to have their head
  coach call plays regardless of who holds the "OC" title, and folding that
  into the mapping (by setting `oc_name` to the actual playcaller, not the
  nominal titleholder, and flagging it) matters directly for whether the
  tendency profile resets when the titled OC changes. It doesn't.
- `src/coordinator/data_prep.py` — loads pbp/ftn/participation and validates
  the join keys before using them.
- `src/coordinator/tendencies.py` — computes per-team-season tendency metrics
  from pbp (+ ftn 2022+, + participation for personnel). Writes
  `team_tendency_profiles` (intermediate table, 320 rows).
- `src/coordinator/oc_profiles.py` — re-keys team-season profiles to the OC
  via `oc_assignments.csv` and implements the first-year-OC inheritance
  blend. Writes `oc_tendency_profiles` (final Phase 4 output, 320 rows).

Run order: `python -m src.coordinator.tendencies` then
`python -m src.coordinator.oc_profiles` (the latter calls the former
internally too, so running just the second is sufficient for a full rebuild).

## Join/column validation performed before building on it

- **`xpass`/`pass_oe` already exist in `pbp`** (nflverse ships them
  precomputed) — used directly rather than re-deriving PROE. Coverage
  checked per season 2016-2025 on pass/run plays: 99.7%-99.99% non-null
  every year, including 2016 (99.8%). No re-derivation needed.
- **ftn join key**: `ftn.nflverse_play_id` (NOT `ftn.ftn_play_id`, which is
  FTN's own internal id space and matches 0% of `pbp.play_id`) joined to
  `pbp.play_id` via `ftn.nflverse_game_id == pbp.game_id`. Checked
  2022-2025 pass/run plays: 99.7%-100% match rate. ftn confirmed absent
  entirely pre-2022 (0 rows), consistent with Phase 1's documented gap —
  `play_action_rate` is `NaN` for 2016-2021, not imputed or backfilled.
- **participation join**: `participation.play_id == pbp.play_id` AND
  `participation.nflverse_game_id == pbp.game_id`, both float64. Used for
  personnel-grouping rates. `offense_personnel` is null on ~20% of
  participation rows (81,831 of ~865k) across the window — those plays are
  excluded from the personnel-rate denominator (`n_personnel_plays`) rather
  than silently coded as a phantom group.

## Tendency metrics computed (per team-season)

- `neutral_sec_per_play` — median seconds between snaps for the same
  possession, restricted to win probability 0.20-0.80 and quarters 1-3 (the
  standard "neutral pace" definition used by public analytics sites), with
  a 3-40s sanity band on the gap to exclude review/quarter-end/game-clock
  artifacts. Lower = faster tempo.
- `pass_oe` / `pass_oe_neutral` — mean of pbp's own `pass_oe` column over
  non-garbage-time plays (wp 0.05-0.95, and a tighter wp 0.20-0.80 cut for
  the second column per the spec's explicit neutral-situation ask). Both
  reported since they only differ modestly and there's no strong reason to
  discard either.
- `play_action_rate` — mean of `ftn.is_play_action` on matched plays.
  `NaN` before 2022 (real gap, not backfilled).
- `personnel_11_rate` / `_12_rate` / `_21_rate` / `_other_rate` — share of
  participation-matched offensive snaps in each grouping, parsed from
  `offense_personnel` text via regex (handles both the terse
  `"1 RB, 1 TE, 3 WR"` format and the fuller OL-inclusive format).

## Sanity checks (do known offenses show up as known?)

- **2024 Eagles (Kellen Moore, run-heavy behind Saquon Barkley)**:
  `pass_oe = -8.39`, among the most run-heavy in the league that season. ✓.
- **2024 Bengals (Dan Pitcher/Burrow, pass-heavy)**: `pass_oe = +8.75`,
  second-highest in the league behind Cincinnati's own volume needs. ✓.
- **LA Rams under Sean McVay, 2017-2023**: `personnel_11_rate` runs
  80-95% across the span (vs. a league-wide norm closer to 55-65%) and
  `neutral_sec_per_play` sits in the high-20s (26-29s) — both match McVay's
  well-known 11-personnel, fast-tempo identity, and the profile stays
  consistent across the 2019→2020 (McVay→O'Connell titled-OC) and
  2021→2022 (O'Connell→Coen) transitions, which is the expected result of
  keying by the actual playcaller (McVay throughout) rather than the
  nominal OC title.
- **Ravens under Greg Roman, 2019-2022 (Lamar Jackson-era run scheme)**:
  `pass_oe` is strongly negative every year (-2.2 to -11.1), the most
  run-heavy sustained stretch in the dataset. ✓.

## Inheritance rule (judgment call — see `src/coordinator/oc_profiles.py`)

For a first-year-in-seat OC, `inherited_<metric>` = weighted blend of the
team's own profile from the prior season and the incoming OC's own profile
from their most recent prior play-calling stop (found by looking up their
name anywhere in `oc_assignments` before the current season):

| `promotion_type` | weight on team's prior-season profile | weight on OC's own track record |
|---|---|---|
| `internal` (e.g. promoted from passing-game coordinator on the same staff) | **70%** | 30% |
| `outside_hire` (from another franchise or college) | 30% | **70%** |

This is a documented judgment call, not fit to any outcome data — the
directional logic (internal promotions preserve more system continuity;
outside hires more often install their own system) is defensible but the
exact 70/30 split is a starting point for the project owner to revisit once
Phase 4/backtest results are in. When the incoming OC has no prior
play-calling stop at all (rookie OC, or hired straight from a
non-play-calling college/staff role), there's nothing to blend with, so the
row falls back to 100% team-prior-season and is flagged
`inheritance_basis = 'team_only_no_oc_history'` rather than silently
applying the weight table to a missing value.

Result counts across all 320 rows (updated after the Aug 2026 CSV
corrections): 191 `returning`-status rows have no inherited profile (not
needed — actual observed pbp is used), 78 first-year rows fell back to
team-only (no OC history found), and 51 first-year rows got a real
weighted blend of both.

## OC attribution confidence

Every row in `oc_assignments.csv` carries an explicit `confidence` column
(no attribution is presented as unqualified fact) and a `notes` column
explaining the reasoning or the specific uncertainty:

| Confidence | Count | What it means |
|---|---|---|
| high | 195 | Verified against Wikipedia team-season pages, contemporaneous hire/firing news coverage (NFL.com, ESPN, team beat sites), or a long, well-documented tenure (Belichick/McDaniels-NE, Reid/KC, Payton-Carmichael/NO, Shanahan/SF, McVay/LA, Haley-Fichtner-Canada/PIT, etc.) |
| medium | 125 | Either not yet independently re-verified against a primary source, or verified but genuinely ambiguous (e.g. a mid-season play-calling handoff whose exact week-by-week split couldn't be pinned down) |
| low | 0 | none remaining — see below |

A full re-verification pass (Aug 2026) checked all 188 rows that were
previously `confidence ∈ {medium, low}` against Wikipedia team-season pages
and contemporaneous hire/firing coverage. Every row that was `low` is now
either confirmed and promoted to `high`, or corrected and promoted to
`high` with the correction spelled out in `notes` — no `low`-confidence
rows remain. Of the 188 rechecked rows, roughly two dozen turned out to
contain outright errors (wrong prior team/role, wrong promotion_type, or in
a few cases the wrong person entirely for a given season — e.g. the 2023 LA
Rams OC was Mike LaFleur, not a returning Liam Coen; the 2023 NO Saints OC
was a returning Pete Carmichael Jr., not Klint Kubiak's first year; the 2016
TB Bucs OC was Todd Monken from year one, not "Koetter (HC), no OC
identified"). All corrections are recorded in `notes` rather than silently
overwritten. A little over 120 `medium` rows were not part of this pass's
priority order (see the report's revision note below) and remain
`medium` pending a future re-verification pass.

**The self-caught O'Connell inconsistency has been resolved.** The CSV's
WAS-2019 and LA-2020 rows for Kevin O'Connell previously pointed in
contradictory directions (each claimed the other team as its own "prior"
team). Verified career path: O'Connell was Washington's QB coach (2017),
then passing-game coordinator (2018), then was promoted internally to OC
for 2019 (Jay Gruden, and after Gruden's Week 5 firing, O'Connell himself,
called plays that season); he was then hired away by the Rams in Jan 2020
directly from that WAS OC role. Both rows are now mutually consistent and
`confidence=high`, with the correction documented in each row's `notes`.
**This was not the only such error in the hand-curated table** — treat
`confidence=medium` rows as "plausible, not yet independently verified,"
and don't assume a clean table just because `low` no longer appears.

## Known modeling simplifications / caveats for the project owner to weigh in on

1. **HC-as-playcaller teams**: for SF (Shanahan), NO 2016-2021 (Payton over
   Carmichael), and partially LA/GB/MIA (McVay coaching tree), `oc_name` is
   set to the head coach rather than the titled coordinator, so the
   tendency profile correctly doesn't reset when the nominal OC title
   changes underneath them. This is the right call for tendency modeling
   but means `oc_name` is not always literally "the offensive coordinator."
   Flagged via `hc_is_playcaller=True` on 73 rows (updated from 67 after
   the Aug 2026 re-verification pass corrected several rows, e.g. Adam
   Gase-MIA 2016-2017, O'Brien-HOU 2016, Koetter-TB 2016-2018, and
   Ben Johnson-CHI 2025).
2. **OC identity is matched by name string**, not a stable ID — two
   different real people with the same name would silently merge. Not
   observed in this 320-row set, but worth a note if the table is extended.
3. **Neutral pace and PROE are team-level, not adjusted for opponent
   strength or roster talent** — a fast/pass-heavy number partly reflects
   personnel (e.g. trailing/leading tendencies of a specific QB), not just
   coordinator preference. Phase 4 should treat these as team-scheme
   priors, not isolated coordinator skill.
4. **Personnel-rate denominator varies by season** (`n_personnel_plays`
   column, min 812, median ~1,052, max 1,341 across the 320 rows) — treat
   rates built on the lower end of that range with a little more caution.
5. **`inheritance_basis` for `oc_only_no_team_history` never actually
   triggers in this window** since every team has a prior season back to
   2015/2016 is the floor — this branch exists in the code for
   completeness/future-proofing (e.g. an expansion team) but is currently
   dead in practice.
